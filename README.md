# AI Multi-Language Translator

An AI-powered multilingual translation web application built using Python, Gradio, Hugging Face Transformers, and PyTorch.

## Features

- Automatic language detection
- Translation between 100+ languages
- User-friendly web interface
- Powered by Facebook M2M100 model
- Real-time translation

## Technologies Used

- Python
- Gradio
- Transformers
- PyTorch
- LangDetect
